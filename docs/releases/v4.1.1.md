## Damon DSP v4.1.1

The first build signed with the stable Damon DSP release key, and the first
cut as a GitHub Release. Everything built under the Damon DSP brief so far is
in it.

### New since RootlessViPER4Android 4.0.0

- **Damon DSP.** The app, its packages, the Magisk module and the workflows
  carry the product name. App labels are *Damon DSP* (rootless,
  `com.arrears.damondsp.rootless`) and *Damon DSP (Root)* (rootful,
  `com.arrears.damondsp.rootful`). The module is `damondsp_engine`; installing
  it removes the old `rv4a_engine` module on the reboot the install asks for.
  The system effect reports itself as *Damon DSP engine v4*.
- **Feature 1: Sub-harmonic generator.** An Epicenter-style stage that grows
  an octave below the bass that is already there. It runs inside a new bass
  block: a linear-phase FIR split at 120 Hz, so the mids and highs are never
  filtered and the block is a bit-exact delay when nothing is enabled. The
  detector reads the mono low band, the sub-octave oscillator is phase-locked
  without steps, the output is low-passed at 80 Hz (8th order), and what the
  stage adds goes through a lookahead gain dip so bass alone never reaches the
  master limiter. Controls: Mix (default −12 dB), Sweep, Wide, Dynamic. Works
  in both the rootless and the rooted build, at any sample rate.
- **Chain order dialog** now also lists Vinyl and Balance.
- **Stable signing.** Every APK is signed with one release keystore kept in the
  repository's secrets, verified with apksigner on every run; the certificate
  SHA-256 is printed in the build log and below.
- **One flash, both halves.** The Magisk module now carries the signed rootful
  app and installs it when flashed from the Magisk app.
- **Releases publish themselves.** Pushing a `v*` tag builds, signs, checks and
  publishes a GitHub Release with the module zip and both APKs attached.

### Carried over from 4.0.x

The Magisk module rewrite (boot watchdog that works, per-format config
validation, AML coexistence, quarantine that distinguishes a bad boot from a
bad file), the use-after-free fix in the system effect, and the app list that
names what to process rather than what to skip.

### Not in this release

Features 2 to 16 of the brief are not started; they land one feature per
session, in the brief's order (2, 3, 16, then 4 onward). Nothing here has
been listened to on hardware yet: the sub-harmonic defaults are the brief's
and will want tuning by ear on the Redmi Note 10 Pro.
